# sb4ssman.github.io

The published files for **[sb4ssman.github.io](https://sb4ssman.github.io/)**: what I've built,
what it did, and the story behind each project.

## What's here

| Path | What it is |
|---|---|
| `index.html` | The page: projects and ventures as cards. Tap a card to read its story. |
| `posts/` | Each story as its own page, plus a list of them all. |
| `fonts/` | Self-hosted Space Grotesk and JetBrains Mono, with their licenses. |

These are built files. A static-site builder generates them from a private source repository, and
each release replaces them, so changes made here directly are overwritten.

## Privacy

Visits are counted with [GoatCounter](https://www.goatcounter.com/): no cookies and no personal
data, and browsers that send Do Not Track are not counted. The page loads no other third-party
scripts and requests no fonts from anyone else.
